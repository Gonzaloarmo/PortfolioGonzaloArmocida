# Gonzalo OS

Portfolio de Gonzalo Armocida. Sitio estático: `index.html` + `assets/`.

## Publicar en Vercel
1. Subí esta carpeta a un repositorio de GitHub.
2. En vercel.com → Add New → Project → importá el repo.
3. Framework Preset: **Other**. Sin build command. Output directory: raíz.
4. Deploy.
